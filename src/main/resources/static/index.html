    How to use FileNest

    1. 1

      Drag a file in, or click to browse

      Drop it onto the upload box, or click the box to open your file picker.

    2. 2

      Save the passkey you're given

      A code appears after upload — write it down. Want to pick your own instead? Type up to 5 letters or digits (a mix of both is best) into the passkey bar before uploading.

    3. 3

      Load your files from any device

      Enter that passkey in the bar up top and hit “Load files” — the same code works on your phone, laptop, anywhere. Hopefully 😭

    4. 4

      Open or delete (within 7 days)

      Each file in your list has an Open and a Delete button — press Delete twice to confirm. Please delete your files within 7 days of uploading them.
